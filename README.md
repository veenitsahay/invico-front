# Invinco Frontend (Vite + React + TypeScript)

This project now uses Vite for local development and production builds.

## Scripts

- `npm run dev` or `npm start`: Start the Vite dev server.
- `npm run build`: Create a production bundle in `dist/`.
- `npm run preview`: Preview the production build locally.
- `npm test`: Run tests with Vitest.

## Getting Started

1. Install dependencies:
   - `npm install`
2. Start development server:
   - `npm run dev`
3. Open the local URL printed in the terminal (typically `http://localhost:5173`).

## Notes

- Static assets are served from `public/` and are available from `/` in code.
- App entry point is `index.html` at the project root and `src/index.tsx`.
